# Decisions

| #   | Decision                                                                                                                                                                                                                                                                                                                            | Why                                                                                                                                                                                                                                                                                                                                                                  | Reversible? |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 1   | Next.js 16 App Router with `output: 'export'`                                                                                                                                                                                                                                                                                       | Pure static hosting, offline PWA, zero env vars. Costs: no per-request CSP nonces → hashed CSP via post-build `_headers` (Phase 8).                                                                                                                                                                                                                                  | Yes         |
| 2   | Pin TypeScript 6 (not 7)                                                                                                                                                                                                                                                                                                            | typescript-eslint does not yet support TS 7.0. Revisit when it does.                                                                                                                                                                                                                                                                                                 | Yes         |
| 3   | Self-host Excalidraw fonts via `scripts/copy-excalidraw-assets.mjs` into `public/excalidraw-assets` (gitignored, generated on `predev`/`prebuild`) and set `window.EXCALIDRAW_ASSET_PATH`                                                                                                                                           | Offline + strict CSP; e2e asserts no external requests. Full font set is ~14 MB (includes CJK); trim/lazy-cache in Phase 8.                                                                                                                                                                                                                                          | Yes         |
| 4   | Editor route is `/app` with `?scene=` (canonical `/app`)                                                                                                                                                                                                                                                                            | Static export cannot pre-render user scene IDs.                                                                                                                                                                                                                                                                                                                      | Yes         |
| 5   | Theme tokens as CSS variables + `data-theme` attribute; Tailwind 4 `@theme inline`                                                                                                                                                                                                                                                  | Single source for marketing pages and editor chrome, dark mode without flash on static pages.                                                                                                                                                                                                                                                                        | Yes         |
| 6   | e2e Chromium via `CHROMIUM_PATH`; Firefox/WebKit behind `ALL_BROWSERS=1` (CI)                                                                                                                                                                                                                                                       | Sandbox only ships one Chromium build.                                                                                                                                                                                                                                                                                                                               | Yes         |
| 7   | Elkjs (not dagre) for auto-layout, Serwist for service worker                                                                                                                                                                                                                                                                       | dagre is unmaintained; `@serwist/next` assumes webpack while Next 16 defaults to Turbopack.                                                                                                                                                                                                                                                                          | Yes         |
| 8   | Optimistic concurrency via per-page `rev` checked inside the write transaction (instead of Web Locks)                                                                                                                                                                                                                               | Atomic, no lock starvation, works across tabs/workers; conflicts surface as a dialog with Merge (Excalidraw `reconcileElements`) / Reload / Keep mine.                                                                                                                                                                                                               | Yes         |
| 9   | Blobs are content-addressed (SHA-256); GC by reachability (pages, snapshots, thumbnails) rather than refcounts                                                                                                                                                                                                                      | Refcounts drift on crashes; reachability is self-healing.                                                                                                                                                                                                                                                                                                            | Yes         |
| 10  | Deleted elements are dropped on save                                                                                                                                                                                                                                                                                                | They only matter for collab reconciliation; undo history is in-memory.                                                                                                                                                                                                                                                                                               | Yes         |
| 11  | Remount `<Excalidraw>` per scene (keyed) instead of `updateScene`                                                                                                                                                                                                                                                                   | Resets undo history so undo never crosses scenes; simpler and safer.                                                                                                                                                                                                                                                                                                 | Yes         |
| 12  | Import never overwrites: every imported scene/folder/page gets fresh ids                                                                                                                                                                                                                                                            | Re-importing a backup yields copies, never data loss.                                                                                                                                                                                                                                                                                                                | Yes         |
| 13  | Persisted schema v1 + pure `upgradePage` for older rows (v0 fixture in tests/fixtures); rows from a _newer_ schema are refused, not downgraded                                                                                                                                                                                      | Never lose data on upgrade or rollback.                                                                                                                                                                                                                                                                                                                              | No          |
| 14  | `pnpm patch` of `@excalidraw/excalidraw@0.18.1` (`patches/`) so the font-subsetting worker is loaded from `/excalidraw-assets/subset-worker.chunk.js`                                                                                                                                                                               | Bundlers rewrite the worker's `import.meta.url` to a `file://` path, so the worker never started, logging a console error on every export and silently using the main thread. The patch changes one expression; no engine behaviour is altered. `scripts/copy-excalidraw-assets.mjs` copies the worker + sibling chunks to `public/`. Remove when upstream fixes it. | Yes         |
| 15  | PDF text: decode the exact woff2 glyph subsets Excalidraw embeds in its SVG (wawoff2 → TTF) and register them with jsPDF; one text run per font                                                                                                                                                                                     | Vector PDF with selectable text _and_ fonts matching the screen, without shipping our own font files.                                                                                                                                                                                                                                                                | Yes         |
| 16  | wawoff2's emscripten glue is loaded as a same-origin classic script (`/excalidraw-assets/woff2-decompress.js`), not imported                                                                                                                                                                                                        | Its Node-only `module.exports` makes the bundled import export nothing in browsers. A script tag needs no `eval`. The wasm is a base64 data URI decoded via `fetch`, so the Phase 8 CSP needs `connect-src data:` (or switch to a `.wasm` file).                                                                                                                     | Yes         |
| 17  | opentype.js pinned to 1.3.x                                                                                                                                                                                                                                                                                                         | 2.0.0 emits `NaN` quadratic control points for glyf outlines (reproduced with Excalifont).                                                                                                                                                                                                                                                                           | Yes         |
| 18  | Export options are sanitized/clamped on load and remembered in IndexedDB settings                                                                                                                                                                                                                                                   | Stored settings are untrusted input; remembers last-used options across sessions.                                                                                                                                                                                                                                                                                    | Yes         |
| 19  | Excalidraw's built-in export/save/load menu actions are disabled in favour of ours                                                                                                                                                                                                                                                  | One export path with preview, progress, cancel and PDF; scenes persist automatically so "save to file" would be misleading.                                                                                                                                                                                                                                          | Yes         |
| 20  | Icons are extracted at build time from `@iconify-json/*` devDependencies into `public/icons/<set>.json` + `index.json`, committed, and fetched lazily per set                                                                                                                                                                       | Only the ~430 curated icons ship (≈0.7 MB, loaded on demand); no runtime dependency on Iconify. `pnpm icons:build` regenerates; the build fails if a set's SPDX license is not CC0/MIT/Apache-2.0/ISC.                                                                                                                                                               | Yes         |
| 21  | Icons enter the scene as SVG data-URL image elements (content-hash deduped), with `currentColor` resolved at insert time                                                                                                                                                                                                            | Crisp at any zoom, tiny files, survives plain Excalidraw. PDF export inlines them as nested `<svg>` (svg2pdf mis-sizes Excalidraw's `<symbol><image>` structure), re-sanitizing the decoded SVG.                                                                                                                                                                     | Yes         |
| 22  | Every SVG entering the app (file, drop, paste, textarea, online icon, SVG embedded in a loaded scene when exporting to PDF) goes through `sanitizeSvg` (DOMPurify SVG profile + hooks): no script/foreignObject/animation, no external or javascript: URLs, CSS `url()` only to `#fragments`, `@import` removed, size and node caps | CLAUDE.md rule: imports are untrusted. 17-case attack corpus in `tests/unit/svg-sanitize.test.ts`.                                                                                                                                                                                                                                                                   | No          |
| 23  | Online icon search is opt-in (default off), allowlisted to permissive sets, refs validated by regex, bodies sanitized, `credentials: omit`, `no-referrer`                                                                                                                                                                           | Privacy: search text leaves the browser only after an explicit toggle.                                                                                                                                                                                                                                                                                               | Yes         |
| 24  | Inserts are single groups with `customData.archboard = { kind, id }` and avoid overlapping existing content (spiral search near the viewport centre)                                                                                                                                                                                | Portable (degrades to plain shapes) and lets Phase 5 recognise inserted components.                                                                                                                                                                                                                                                                                  | Yes         |
| 25  | Smart Components are generated by pure functions that return _parts with stable roles_; the role becomes the element id (`sc_<instance>_<role>`) and bound-text id (`…:label`)                                                                                                                                                      | Stable ids are what make regeneration-in-place, external arrow bindings and undo work without a diffing heuristic.                                                                                                                                                                                                                                                   | Yes         |
| 26  | Regeneration merges `generate(oldProps)` (baseline) with `generate(newProps)`: a field differing from the baseline is a user override and is kept                                                                                                                                                                                   | Detects hand edits without storing a shadow copy of the generated state, and works after reload or file sharing.                                                                                                                                                                                                                                                     | Yes         |
| 27  | Custom components are declarative JSON (`archboard.smart/1`), validated strictly and never evaluated; the definition is embedded in the root element's `customData`                                                                                                                                                                 | Satisfies "no code required" and "sandboxed" without running user code; shared files stay editable anywhere. A TypeScript-like scripting layer was rejected as an unnecessary attack surface.                                                                                                                                                                        | Yes         |
| 28  | Converter output is post-processed in `materialize`: arrows are routed between bound shapes (the converter binds but does not position them), seeds are `hash(role)`                                                                                                                                                                | Deterministic, pixel-stable output enables visual regression tests and stable diffs.                                                                                                                                                                                                                                                                                 | Yes         |
| 29  | Dexie schema bumped to v2 (adds `smartDefs`); v1 databases open unchanged                                                                                                                                                                                                                                                           | Additive migration, covered by a legacy-database test.                                                                                                                                                                                                                                                                                                               | No          |
| 30  | Ports are named references to the part's element (not extra dot elements)                                                                                                                                                                                                                                                           | Avoids visual clutter in exports; arrows bind to the part itself.                                                                                                                                                                                                                                                                                                    | Yes         |
| 31  | Page = one Dexie `pages` row; switching remounts the engine (key includes page id) and remembers the last page per scene in settings                                                                                                                                                                                                | Reuses the proven autosave/conflict path per page with no new engine state.                                                                                                                                                                                                                                                                                          | Yes         |
| 32  | Version history is gzip'd JSON in `snapshots`; retention buckets (5 min/1 h, hourly/24 h, daily/30 d), named and pre-restore copies kept; restore first saves a pre-restore copy                                                                                                                                                    | Restore is always reversible and storage stays bounded.                                                                                                                                                                                                                                                                                                              | Yes         |
| 33  | Auto-layout uses ELK (`elkjs`) in a Web Worker (bundled build in Node/tests); groups and bound labels move as units; one outermost wrapper group (what inserts create) is looked through, then restored                                                                                                                             | Orthogonal routing and five layouts; dagre is unmaintained.                                                                                                                                                                                                                                                                                                          | Yes         |
| 34  | The diagram DSL is a hand-written parser (no dependency) → compile → Excalidraw skeletons → ELK; it never throws and returns line/column diagnostics                                                                                                                                                                                | Live error squiggles, 150-node cap, no code execution.                                                                                                                                                                                                                                                                                                               | Yes         |
| 35  | Share links: gzip → AES-256-GCM, key and data in the `#fragment` (never sent to a server); warn at 8,000 chars, refuse at 32,000; payload validated and SVG sanitized on open; view mode is an ephemeral read-only canvas                                                                                                           | No backend or account; honest size guard with an export fallback.
