# Security model

- **No accounts, cookies or backend.** Everything is client-side; scenes live in IndexedDB. Share links keep the key in the URL fragment, which browsers do not send to servers.
- **Untrusted input.** SVG (files, paste, drop, share links, embedded in scenes) goes through the DOMPurify-based sanitizer; share payloads and backups are validated and size capped; Mermaid runs with its strict security level; templates and the DSL never evaluate code.
- **Content Security Policy** (generated by `scripts/build-pwa.mjs` into `out/_headers` and `out/csp.txt`):
  - `script-src 'self' 'wasm-unsafe-eval'` plus a SHA-256 hash for each inline script the static export emits (static export has no per-request nonce). No `unsafe-eval`, no `unsafe-inline` for scripts.
  - `style-src 'self' 'unsafe-inline'`: unavoidable, Excalidraw and Radix set inline style attributes at runtime.
  - `connect-src 'self' https://api.iconify.design` (the host is only used after an explicit opt-in), `img-src 'self' data: blob:`, `frame-src 'none'`, `object-src 'none'`, `frame-ancestors 'none'`.
  - The page policy is attached to HTML routes only. The WOFF2 font decoder (emscripten, needs `new Function`) runs in `woff2-worker.js`, a worker with no DOM and no network that is served with its own narrower policy allowing eval. This keeps eval out of the page.
  - Other headers: `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` (camera, microphone, geolocation and payment off), `Cross-Origin-Opener-Policy`.
- **Tested.** `tests/e2e/hardening.spec.ts` replays the shipped policies in a real browser while using the DSL, Mermaid, PNG/SVG/PDF export (including text outlines), share links and the dialogs, and fails on any violation except Excalidraw's third-party font fallback (see KNOWN_GAPS).
- **Hosting.** `_headers` works on Netlify and Cloudflare Pages. On other hosts, translate `out/_headers` (for nginx, S3/CloudFront, Vercel, and so on) and rebuild it whenever the build changes, because the script hashes change with the build.
- **Service worker.** Same-origin GET only; never caches IndexedDB data; updates are offered with a Reload button rather than applied silently.
